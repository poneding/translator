## What still needs a human (referenced by `qa/CHECKLIST.md`)

The full BH-1 through BH-14 behavior set is enumerated in `qa/CHECKLIST.md`.
A human must exercise the installed bundle and tick the boxes. The boxes
that need a GUI + OS input device:

- Tray left-click opens settings (BH-14.1)
- Global hotkey actually fires the popup (BH-3.1)
- Selection read from another app (browser, editor) (BH-3.1)
- Always-on-top / borderless / transparent rendering (BH-5.1)
- Click-outside dismissal with 500 ms grace (BH-5.8)
- Popup does not steal focus (BH-6.5)
- All 5 services return real translations end-to-end
- Permission prompt on first run (BH-3.3)
- Cold-start < 2.5 s on the test host (SPEC §4.1)
- Idle memory < 50 MB (SPEC §4.1)
- macOS template-image tray icon (BH-14.3) — not testable on Windows
