## Manual checklist (to be performed on a real Ubuntu 22.04 install)

### Installation
- [ ] `sudo dpkg -i translator_0.1.0_amd64.deb && sudo apt-get install -f`
- [ ] Or: `chmod +x translator_0.1.0_amd64.AppImage && ./translator_0.1.0_amd64.AppImage`
- [ ] App icon appears in system tray (top bar, color image)

### Hotkey (BH-1.x)
- [ ] Default `Ctrl+Shift+D` works in any focused app
- [ ] Popup appears at selection position
- [ ] Pressing hotkey while popup visible hides it
- [ ] Change hotkey in Settings; new binding applies without restart

### Selection (BH-2.x)
- [ ] Selected text in Firefox/gedit is read correctly (atspi via D-Bus)
- [ ] Empty selection → "No text is selected" message
- [ ] If `dbus-daemon` is not running → `SelectionError::Platform` in popup
- [ ] Long selection (> 100 000 chars) → truncated with warning

### Permission (BH-3.x)
- [ ] No permission prompt needed (atspi works out of the box)
- [ ] `open_permission_settings` is a no-op on Linux

### Translation (BH-4.x)
- [ ] At least one service configured — translations appear
- [ ] Parallel dispatch
- [ ] Per-service 8 s timeout
- [ ] Failing service shows error tab, not crash

### Popup (BH-5.x, BH-6.x)
- [ ] Borderless, transparent, always-on-top
- [ ] Source text in muted box
- [ ] Copy button works + flashes "Copied" 1.5 s
- [ ] Click outside → 500 ms grace
- [ ] Escape hides popup
- [ ] Popup does not steal focus

### Settings (BH-7.x through BH-12.x)
- [ ] 5 sections in sidebar
- [ ] Resizable, size persists
- [ ] Service status dots
- [ ] Youdao + OpenAI rows expand correctly
- [ ] BCP-47 validation
- [ ] Hotkey validation
- [ ] Theme selector
- [ ] About section

### Localization (BH-13.x)
- [ ] Set system locale to `zh_CN` → UI is in Chinese
- [ ] Set system locale to `en_US.UTF-8` → UI is in English

### System integration (BH-14.x)
- [ ] Tray icon is color (not template)
- [ ] Tray menu: Open Settings + Quit
- [ ] Closing settings/popup does NOT quit
- [ ] `pkill translator` cleanly exits

### Performance (§4.1)
- [ ] Cold start to tray: < 2.5 s
- [ ] Hotkey to popup: < 150 ms
- [ ] Memory idle: < 50 MB
- [ ] Binary size: ~9 MB (AppImage is larger than raw exe; acceptable)

### Reliability (§4.3)
- [ ] Disable network → per-service errors, no crash
- [ ] Corrupt `config.json` (rename to .bak) → recreated with defaults
- [ ] Idle: no CPU usage (check `top` or `htop`)

### Secret Service (Linux-specific)
- [ ] API keys stored in GNOME Keyring / KWallet via `keyring` crate
- [ ] `seahorse` shows the `dev.translator.desktop` entries (if GNOME)
- [ ] Removing an entry from seahorse → service status dot turns red
