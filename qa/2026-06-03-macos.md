## Manual checklist (to be performed on a real Mac)

### Installation
- [ ] Drag `.dmg` → Applications
- [ ] First launch: right-click → Open (Gatekeeper ad-hoc prompt)
- [ ] Grant Accessibility permission in System Settings → Privacy & Security
- [ ] App icon appears in menu bar (template image, monochrome)

### Hotkey (BH-1.x)
- [ ] Default `Cmd+Shift+D` works in any focused app
- [ ] Popup appears at selection position
- [ ] Pressing hotkey while popup visible hides it
- [ ] Change hotkey in Settings; new binding applies without restart
- [ ] If a conflicting app is running, red banner appears and default resets on next launch

### Selection (BH-2.x)
- [ ] Selected text in Safari/TextEdit is read correctly
- [ ] Empty selection → "No text is selected" message (no crash)
- [ ] Very long selection (> 100 000 chars) → truncated with warning

### Permission (BH-3.x)
- [ ] First launch triggers the Accessibility prompt
- [ ] "Open Settings" button in popup opens `x-apple.systempreferences:...Privacy_Accessibility`
- [ ] After granting permission, pressing hotkey again works

### Translation (BH-4.x)
- [ ] At least one service configured (e.g. DeepL) — translations appear in tabs
- [ ] All enabled services dispatched in parallel
- [ ] A failing service (e.g. invalid key) shows an error tab, not a crash
- [ ] Priority order in popup matches Settings → Services

### Popup (BH-5.x, BH-6.x)
- [ ] Popup is borderless, transparent, always-on-top, non-resizable
- [ ] Popup appears on the correct monitor (multi-monitor test)
- [ ] "Translating…" loading state visible during request
- [ ] Source text shown in muted box at top
- [ ] Copy button copies result to clipboard, flashes "Copied" 1.5 s
- [ ] Click outside popup → hides after 500 ms (reset if focus returns)
- [ ] Escape hides popup
- [ ] Popup does NOT steal focus from source app

### Settings (BH-7.x, BH-8.x, BH-9.x, BH-10.x, BH-11.x, BH-12.x)
- [ ] Settings opens from tray menu
- [ ] 5 sections in left sidebar: General, Services, Hotkey, Appearance, About
- [ ] Resize settings window; size persists
- [ ] Service row shows status dot (green/red/yellow)
- [ ] Youdao row expands to App Key + App Secret
- [ ] OpenAI row expands to Base URL + Model + API Key + Presets dropdown
- [ ] Saving a key shows green toast "Saved to OS Keychain" 2 s
- [ ] Target language dropdown has 12 SPEC options
- [ ] BCP-47 validation rejects malformed codes
- [ ] Hotkey input validates syntax
- [ ] Theme selector: System / Light / Dark
- [ ] About section shows version, commit, build date, repo link

### Localization (BH-13.x)
- [ ] Set system language to Simplified Chinese → UI is in Chinese
- [ ] Set system language to English → UI is in English

### System integration (BH-14.x)
- [ ] Menu bar icon is monochrome template (adapts to light/dark menu bar)
- [ ] Tray menu: Open Settings + Quit
- [ ] Quit via tray menu exits process
- [ ] Closing settings/popup does NOT quit

### Performance (§4.1)
- [ ] Cold start to tray visible: < 1.5 s on Apple M1
- [ ] Hotkey to popup: < 150 ms
- [ ] Memory idle: < 50 MB
- [ ] Binary size: ~8-9 MB (over < 8 MB target on Universal; documented)

### Reliability (§4.3)
- [ ] Disable network → translations fail per-service, no crash
- [ ] Corrupt `config.json` (rename to .bak and launch) → recreated with defaults
- [ ] Idle: no CPU usage (check Activity Monitor)
